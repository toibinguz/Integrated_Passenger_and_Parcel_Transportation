# Total vertices in the network: V = 2*N + 2*M + K
# Vertices are 1-indexed: 1, 2, ..., V
#
# Line 1:
#   K N M
#     K : Number of taxis
#     N : Number of passenger requests
#     M : Number of parcel requests
#
# Next K lines (Taxis: k = 1..K):
#   O_k Q_k
#     O_k : Initial depot / location vertex of taxi k (available at time 0)
#     Q_k : Parcel capacity of taxi k
#
# Next N lines (Passenger requests: i = 1..N):
#   P_i D_i E_i L_i S_i T_i
#     P_i : Pickup vertex
#     D_i : Drop-off vertex
#     E_i : Earliest pickup time (pickup window [E_i, L_i])
#     L_i : Latest pickup time
#     S_i : Service duration for both pickup and drop-off
#     T_i : Revenue for serving this passenger
#     (Note: taxi must travel directly from P_i to D_i with no other stops)
#
# Next M lines (Parcel requests: j = 1..M):
#   P_j D_j w_j Ep_j Lp_j Ed_j Ld_j S_j T_j
#     P_j   : Pickup vertex
#     D_j   : Drop-off vertex
#     w_j   : Parcel weight (must not exceed taxi remaining capacity)
#     Ep_j  : Earliest pickup time (pickup window [Ep_j, Lp_j])
#     Lp_j  : Latest pickup time
#     Ed_j  : Earliest drop-off time (delivery window [Ed_j, Ld_j])
#     Ld_j  : Latest drop-off time
#     S_j   : Service duration for both pickup and drop-off
#     T_j   : Revenue for serving this parcel
#
# Next V lines (Travel time matrix t(u, v), V rows x V columns):
#   Row u contains t(u, 1), t(u, 2), ..., t(u, V)
#
# Next V lines (Travel cost matrix c(u, v), V rows x V columns):
#   Row u contains c(u, 1), c(u, 2), ..., c(u, V)
# ==============================================================================

# Output Format Template and Specification
# ==============================================================================
# Line 1:
#   Benefit
#     The total net revenue / objective value calculated by the participant:
#     Benefit = sum(passenger revenues) + sum(parcel revenues) - sum(travel costs)
#
# Next K lines (Route for Taxi 1, Taxi 2, ..., Taxi K):
#   m_k v^k_1 v^k_2 ... v^k_{m_k}
#
# Where:
#   - m_k : Number of service points visited by taxi k (m_k >= 0) (not including initial depot)
#   - v^k_1, ..., v^k_{m_k} : The ordered sequence of visited service vertices
#     (Each taxi implicitly starts at its initial depot O_k at time 0).
#   - If taxi k is not used, simply output: 0
#
# Constraints to satisfy:
#   1. Passenger direct trip: For any served passenger i, drop-off D_i^n must
#      immediately follow pickup P_i^n in the same route.
#   2. Parcel pickup before delivery: For any served parcel j, pickup P_j^h must
#      appear before drop-off D_j^h in the same taxi's route.
#   3. Taxi parcel capacity: Current load at any point cannot exceed Q_k.
#   4. Time windows:
#      - Passenger pickup: arr(P_i^n) <= L_i^n
#      - Parcel pickup: arr(P_j^h) <= L_j^{h,p}
#      - Parcel delivery: arr(D_j^h) <= L_j^{h,d}
#   5. Every served request is assigned to at most one taxi (partial service not allowed).
# ==============================================================================
